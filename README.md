langkah 1: Membuat Dokumen HTMLDi tahap awal ini, kita bikin file HTML baru dinamai lab2_css_dasar.html. Isinya cuma kerangka dasar halaman web, mulai dari tag <header>, menu navigasi <nav>, pembungkus <div> dengan id="intro", sampai judul dan paragraf teks biasa. Pokoknya ini dibikin dulu kosongan alias belum ada hiasan CSS-nya.   Langkah 2: Mendeklarasikan CSS InternalKalau kerangkanya udah jadi, kita mulai masukin sedikit styling langsung di dalam file HTML-nya pakai tag <style> di bagian <head> (ini yang dinamakan CSS internal). Di sini kita mulai ubah jenis font buat seluruh <body>, kasih garis bawah (border-bottom) di bagian header, rapikan ukuran dan posisi teks judul h1, serta ganti warna teks miring (<i>) di dalamnya biar kelihatan lebih rapi.   Langkah 3: Menambahkan Inline CSSNah, di langkah ketiga ini kita coba cara lain buat ngasih style, yaitu Inline CSS. Kita tinggal sisipkan atribut style langsung di dalam tag paragraf <p> tertentu. Kelemahannya, cara ini cuma bakal ngefek ke satu baris/elemen itu doang dan nggak bisa dipakai bareng-bareng ke elemen lain.   Langkah 4: Membuat CSS EksternalSupaya kodenya lebih bersih dan rapi, kita buat file CSS terpisah dengan nama style_eksternal.css. File terpisah ini khusus buat ngurusin tampilan menu navigasi (nav), kayak ganti warna background jadi hijau, ngatur padding, sampai nambahin efek warna waktu kursor diarahkan ke menu (hover). Supaya filenya kebaca, kita panggil pakai tag <link> di bagian <head> dokumen HTML.   Langkah 5: Menambahkan CSS Selector (ID dan Class Selector)Di langkah terakhir, kita makin mempercantik tampilannya dengan pakai ID Selector (pakai tanda # untuk #intro) dan Class Selector (pakai tanda titik . buat .button dan .btn-primary) di file CSS eksternal.   ID Selector #intro dipakai buat ngatur kotak pembungkus utama (background, border, padding) serta ngatur teks h1 yang ada di dalamnya.   Class Selector (.button dan .btn-primary) dipakai khusus buat bikin tombol tautan "Informasi selengkapnya" biar bentuknya berubah jadi mirip tombol dengan warna latar belakang merah yang mencolok.

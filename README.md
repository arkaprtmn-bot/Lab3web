Langkah 1: Membuat Dokumen HTMLPenjelasan: Pada langkah pertama ini, kita membuat sebuah file HTML baru dengan nama lab2_css_dasar.html. Dokumen ini berisi struktur dasar HTML yang mencakup tag <header>, <nav> (untuk menu navigasi tautan), elemen pembungkus <div> dengan atribut id="intro", judul (<h1>), paragraf (<p>), serta tombol tautan menggunakan atribut class="button btn-primary". Dokumen ini menjadi kerangka dasar tampilan web sebelum diberikan gaya CSS.   Langkah 2: Mendeklarasikan CSS InternalPenjelasan: Langkah kedua adalah menambahkan kode CSS secara internal di dalam tag <head> menggunakan tag <style>. Pada tahap ini, kita mulai mengatur gaya elemen dasar seperti mengubah jenis huruf (font-family) pada tag <body>, memberikan garis bawah dan tinggi minimum pada tag <header>, mengatur ukuran, warna, serta perataan teks pada tag <h1>, serta mengubah warna teks khusus untuk tag <i> di dalam <h1>.   Langkah 3: Menambahkan Inline CSSPenjelasan: Pada langkah ini, kita menyisipkan Inline CSS secara langsung pada tag tertentu menggunakan atribut style (dalam hal ini ditambahkan pada tag <p>). CSS jenis ini hanya akan memengaruhi satu baris atau satu elemen spesifik tempat atribut tersebut dituliskan tanpa memengaruhi elemen paragraf lain di luar itu.   Langkah 4: Membuat CSS EksternalPenjelasan: Langkah keempat melibatkan pembuatan file terpisah berformat .css dengan nama style_eksternal.css. Di dalam file terpisah ini, kita mendefinisikan aturan gaya untuk menu navigasi (nav dan nav a), termasuk efek interaktif seperti perubahan warna latar belakang saat kursor diarahkan ke tautan (nav a:hover atau kelas .active). File CSS eksternal ini kemudian dihubungkan ke dokumen HTML menggunakan tag <link> di dalam bagian <head>.   Langkah 5: Menambahkan CSS Selector (ID dan Class Selector)Penjelasan: Pada langkah terakhir, kita memperkaya file style_eksternal.css dengan menerapkan ID Selector (ditandai dengan simbol # untuk #intro) dan Class Selector (ditandai dengan simbol titik . untuk .button dan .btn-primary).   ID Selector (#intro) digunakan untuk mengatur kontainer utama secara spesifik (seperti warna latar belakang, border, dan padding) serta mengatur elemen h1 di dalamnya.   Class Selector (.button dan .btn-primary) digunakan untuk mendesain tombol interaktif agar memiliki bentuk, warna, dan dekorasi teks yang dapat digunakan secara berulang pada elemen HTML lainnya.
